# 突然之间发现我已恋上你（Ren'Py 移植版）

视觉小说《突然之间发现我已恋上你》的 Ren'Py 重制版，由原 NScripter 脚本自动转换而来。

## 项目简介

原作为 NScripter 引擎的视觉小说，包含四条女主角路线（詠歌、涼、胤、紡）和完整的分支剧情。本项目将其完整移植到 Ren'Py 引擎，实现了：

- **完整剧情**：158 个剧情标签、约 3 万句台词（21165 句角色台词 + 9120 句旁白）
- **完整音频**：10699 条角色语音、457 首背景音乐、1026 个音效
- **完整画面**：7845 张立绘/背景图、9866 处立绘显示、1756 处背景切换
- **分支系统**：11 个关键剧情选择分支
- **92 位**有名字的登场角色（含组合名如「詠歌＆涼」）

## 运行方式

### 环境要求

- [Ren'Py](https://www.renpy.org/) 8.5 或更高版本
- macOS / Windows / Linux 均可

### 启动

用 Ren'Py 启动器打开项目根目录（`tulian/`），点击「启动项目」。

或命令行直接运行：

```bash
renpy.sh /path/to/tulian
```

## 目录结构

```

├── game/
│   ├── script.rpy      # 转换后的剧情脚本
│   ├── screens.rpy     # 界面定义（主菜单、设置、存档、历史等）
│   ├── gui.rpy         # GUI 主题配置（配色、字体、尺寸）
│   ├── options.rpy     # 游戏选项（分辨率、语言、存档目录等）
│   ├── default.ttf     # 中文字体（MicroHei）
│   ├── images/         # 图片资源（7845 张）
│   ├── bgm/            # 背景音乐（34 首）
│   ├── voice/          # 角色语音（10699 条）
│   ├── se/             # 音效（600 个）
│   ├── tl/chinese/     # 简体中文翻译（覆盖内置英文界面）
│   └── saves/          # 存档（运行时生成，已 git 忽略）
```

> 注：`images/`、`bgm/`、`voice/`、`se/` 四个资源目录体积约 2.8GB，未纳入 git 版本控制（见 `.gitignore`），需从原游戏 APK 自行解包。

## 游戏功能

- **主菜单**：开始游戏、读档、设置、关于、帮助、退出
- **游戏内菜单**：存档、读档、历史记录、设置
- **快捷菜单**（游戏画面底部）：回退、历史、快进、跳跃、自动、存档、快速存档/读档、设置
- **跳跃功能**：一键快进到下一个剧情选择分支
- **存档管理**：带截图缩略图、分页、删除存档（含二次确认）
- **设置项**：显示模式、跳过选项、文字速度、自动前进时间、音乐/音效/语音音量、全部静音
- **历史记录**：回溯已读对话

## 技术说明

### 资源转换流程

1. 从原游戏 APK 提取 `assets/`（含 `0.txt` 脚本和 `arc.nsa` 系列归档）。
2. 使用 `nsaout` 工具解包 `.nsa` 归档，得到 `image/`、`bgm/`、`voice/`、`se/` 四类资源。
3. Python 转换器（`convert.py`）解析 NScripter 脚本，翻译为 Ren'Py 格式。

### 关键实现细节

- **分辨率**：800×450（16:9），与原版一致。
- **立绘定位**：按 ONScripter `lsp2` 的中心坐标语义，用 `Transform` 精确还原。
- **背景**：4:3 素材在 16:9 屏幕居中裁剪显示。
- **语音**：`config.voice_filename_format` 自动补全 `voice/` 前缀。
- **字体**：全界面使用 `default.ttf`（支持简体中文、日文假名）。
- **界面汉化**：通过 `tl/chinese/common.rpy` 翻译文件覆盖 Ren'Py 内置英文界面。

### 转换过程中处理的特殊情况

- **混合编码**：脚本主体为 GB18030 中文，个别路线选择文字为 Shift-JIS 日文，转换时已分别处理。
- **多说话人标签**：个别台词一行含多个 `[1|说话人|语音]` 标签（两人异口同声），已正确拆分。
- **原脚本 bug**：2 处 `goto *L_ry_ei_com06_goryu` 跳转目标未定义，已改为顺序执行。
- **缺失资源**：6 张背景图缺失已回退为黑屏；9 个语音文件缺失已跳过。

### 已知问题

- 立绘坐标按原算法还原，个别复杂立绘叠加场景可能有细微偏移。
- 原作的标题画面、过场动画等特效未完整还原（使用简化版主菜单）。

## 存档兼容性说明

存档与 `script.rpy` 的脚本结构强关联。**若修改了脚本内容（增删标签、调整语句），旧存档可能无法加载**，会提示 "Could not load the game"。此时需删除 `game/saves/` 下的存档文件重新开始。
